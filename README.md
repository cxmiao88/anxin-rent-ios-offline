# 安心租房 iOS 离线版构建仓库

H5 资源打进 App 包内，用自定义协议 `anxin://app` 本地加载，接口由壳内代理转发到 `https://cc.scxjydz.com`（后端没有 CORS 头，必须同源代理）。

- Bundle ID：`com.anxinhuiju.zufang`
- 版本：1.0.7 / 107
- 产物：`AnxinRentOffline.ipa`（未签名），随 Release `v1.0.7-offline` 发布
- 页面资源：构建时从线上 `/h5/` 爬取（与本地构建逐字节一致），写入 `Resources/www/h5`，随包发布

## 与在线壳的区别

| 项 | 在线壳 | 离线版 |
| --- | --- | --- |
| 页面来源 | 每次启动拉线上 `/h5/` | 包内本地文件 |
| 断网 | 白屏 | 界面仍可打开（接口报错照旧） |
| 服务器改版 | 立刻生效 | 不生效，需重新打包 |
| 接口 | 同源直连 | 经壳内代理转发，对页面同源 |
